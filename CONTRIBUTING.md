# Contributing

Thank you for your interest in AXS Audit public resources.

This repository is maintained by Calling All Minds as a public documentation resource for AXS Audit methodology, standards mapping and accessibility guidance.

## What this repository is for

This repository may include:

- Public methodology notes
- WCAG-informed mapping
- Cognitive accessibility guidance
- Reporting structure
- ACT Rules roadmap and future implementation documentation
- Public examples and templates

## What this repository is not for

This repository is not the product source code repository for AXS Audit.

Please do not submit:

- Proprietary code
- Client data
- Private reports
- Security vulnerabilities
- Credentials or secrets
- Confidential product architecture
- Customer information
- Sensitive accessibility findings from live systems

## Issues and suggestions

Suggestions about public documentation may be raised through GitHub issues where enabled.

For commercial enquiries, product demonstrations or accessibility audit requests, please contact Calling All Minds through the website:

https://callingallminds.com
