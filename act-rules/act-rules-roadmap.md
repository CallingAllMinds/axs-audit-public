# ACT Rules Roadmap

This document records the intended approach to ACT Rules documentation for AXS Audit.

## Current status

AXS Audit has been submitted as an automated accessibility audit tool. Formal ACT Rules implementation documentation is not yet published.

## Planned approach

Calling All Minds intends to:

1. Identify which AXS Audit checks map to specific ACT Rules.
2. Confirm whether each mapped check fully, partially or conditionally implements the ACT Rule.
3. Run relevant official ACT Rule test cases.
4. Record results in a public implementation report.
5. Publish the report in this repository or on the Calling All Minds website.
6. Link the report from the W3C Evaluation Tools List submission where appropriate.

## Principles

ACT Rules claims should be:

- Accurate
- Evidence-based
- Limited to implemented checks
- Updated when the product changes
- Clear about limitations

## Candidate areas for future mapping

Potential areas may include:

- Page title checks
- Language attribute checks
- Image accessible name checks
- Button accessible name checks
- Link accessible name checks
- Form label checks
- ARIA attribute validity checks
- Heading and structure checks

No formal claim is made in this document that AXS Audit currently implements these ACT Rules. This list is a roadmap for future validation.
