# WCAG 2.1 and WCAG 2.2 Mapping

AXS Audit is informed by WCAG 2.1 and WCAG 2.2. This file provides a high-level public mapping of areas that may be assessed.

This document is not a formal conformance claim. It is intended to explain the types of issues AXS Audit may help identify.

## Perceivable

AXS Audit may identify issues relating to:

- Text alternatives for non-text content
- Captions or alternatives where applicable
- Meaningful structure and sequence
- Colour contrast
- Text resizing and visual presentation
- Content that may be difficult to perceive

Relevant WCAG areas may include:

- 1.1.1 Non-text Content
- 1.3.1 Info and Relationships
- 1.3.2 Meaningful Sequence
- 1.4.1 Use of Colour
- 1.4.3 Contrast
- 1.4.4 Resize Text
- 1.4.10 Reflow
- 1.4.11 Non-text Contrast
- 1.4.12 Text Spacing

## Operable

AXS Audit may identify issues relating to:

- Keyboard access
- Focus visibility
- Navigation consistency
- Link purpose
- Page titles
- Headings and labels
- Target size where applicable

Relevant WCAG areas may include:

- 2.1.1 Keyboard
- 2.1.2 No Keyboard Trap
- 2.4.1 Bypass Blocks
- 2.4.2 Page Titled
- 2.4.4 Link Purpose
- 2.4.6 Headings and Labels
- 2.4.7 Focus Visible
- 2.4.11 Focus Not Obscured
- 2.5.8 Target Size

## Understandable

AXS Audit may identify issues relating to:

- Language declaration
- Consistent navigation
- Form labels and instructions
- Error identification
- Content clarity
- Cognitive complexity

Relevant WCAG areas may include:

- 3.1.1 Language of Page
- 3.2.3 Consistent Navigation
- 3.2.4 Consistent Identification
- 3.3.1 Error Identification
- 3.3.2 Labels or Instructions
- 3.3.3 Error Suggestion

## Robust

AXS Audit may identify issues relating to:

- Valid roles, states and properties
- Accessible names
- Programmatic relationships
- Compatibility with assistive technologies

Relevant WCAG areas may include:

- 4.1.2 Name, Role, Value
- 4.1.3 Status Messages

## Notes

WCAG mapping will be refined as AXS Audit evolves. Formal ACT Rules implementation reports will be published separately once checks have been mapped and tested against relevant ACT Rule test cases.
