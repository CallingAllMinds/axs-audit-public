# Sample Accessibility Report Outline

This file provides a public example of the type of structure an AXS Audit report may follow. It does not contain client data.

## 1. Executive summary

A short summary of key accessibility, usability and cognitive inclusion findings.

## 2. Overall result

A summary score, rating or maturity indicator, where applicable.

## 3. Priority issues

A list of the most important issues to address first.

## 4. WCAG-informed findings

Findings mapped to relevant WCAG 2.1 or WCAG 2.2 criteria where applicable.

## 5. Cognitive accessibility observations

Findings related to clarity, cognitive load, readability, journey complexity and support for users with cognitive or learning differences.

## 6. Page and journey findings

Findings organised by URL, template, user journey or component.

## 7. Recommendations

Practical steps for improving accessibility and inclusion.

## 8. Suggested prioritisation

Recommendations grouped by urgency, impact and effort.

## 9. Next steps

Suggested actions for product, content, design, development, compliance or leadership teams.
