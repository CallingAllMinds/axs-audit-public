# AXS Audit Public Resources

AXS Audit is an automated accessibility audit tool from Calling All Minds. It helps organisations identify accessibility, usability and cognitive inclusion barriers across websites, digital platforms and online journeys.

This repository contains public information about the AXS Audit methodology, including WCAG-informed checks, W3C WAI cognitive accessibility guidance, reporting structure and future ACT Rules implementation documentation.

AXS Audit is designed to support disabled, neurodivergent and cognitively diverse users by helping organisations understand where digital experiences create barriers and how those barriers can be prioritised for improvement.

## Important note

This repository does not contain proprietary source code, client reports, scanning logic, credentials, internal architecture or private customer information. It is a public documentation resource intended to explain the AXS Audit approach at a high level.

## Standards and guidance

AXS Audit is informed by:

- Web Content Accessibility Guidelines, WCAG 2.1
- Web Content Accessibility Guidelines, WCAG 2.2
- W3C WAI cognitive accessibility guidance
- Making Content Usable for People with Cognitive and Learning Disabilities
- Inclusive design and usability principles

## Future ACT Rules documentation

Calling All Minds intends to document the ACT Rules implemented by AXS Audit where applicable. ACT Rules documentation will be added only where checks have been mapped, tested and evidenced.
