# Disclaimer

This repository is provided for public information and transparency.

The content explains aspects of the AXS Audit approach at a high level. It should not be treated as legal advice, certification, a complete accessibility conformance claim or a substitute for expert accessibility review.

Accessibility is context-dependent. Automated testing can identify many issues, but no automated tool can identify every accessibility barrier. Organisations should use automated testing alongside expert review, user testing, assistive technology testing and ongoing monitoring.

References to WCAG, W3C WAI guidance or ACT Rules are provided to explain the framework informing AXS Audit. They do not imply endorsement by W3C or any other standards body.

Calling All Minds may update this documentation as AXS Audit evolves.
